# Required Features

## Add
User enters a title and optionally subject/due date, then clicks Add Task.

## Complete
Clicking the checkbox changes completed between true and false.

## Edit
Click Edit and allow the user to modify the task information.

## Delete
Click Delete and remove the task.

## Search
Search should match task title or subject.

## Filter
- All = every task
- Pending = completed is false
- Completed = completed is true

Search and filter should work together.

## Counters
- Total = number of all tasks
- Pending = number of incomplete tasks
- Completed = number of completed tasks

Counters update immediately after adding, editing, completing, or deleting.

## Persistence
Every change must be saved to localStorage automatically.
