# StudyMate

A simple student study-task planner built with React + Vite.

## Features
- Add study tasks
- Edit tasks
- Delete tasks
- Mark tasks complete
- Search tasks
- Filter tasks
- Task counters
- localStorage persistence
- Responsive design

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Designed for easy deployment on Vercel.
